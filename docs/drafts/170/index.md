# ディスレクシア — 組み方で変わる文字の読みやすさ

## 今日のゴール

- ディスレクシアが、知的な遅れではなく文字と音の変換の困難だと知る
- 行間・行の長さ・揃え方が、読みにくさを増幅も軽減もすると知る
- CSS の数行と WCAG の基準でどこまで対応できるか知る

## 文字は読めるのに読むのが大変な人がいる

**ディスレクシア**（発達性読み書き障害）は、全体的な発達に遅れはないのに、文字の読み書きだけに困難がある特性です。視力の問題でも、努力の不足でもありません。

英語圏では 10% 前後、日本語話者でも数%から 8% 程度という推計があります。40 人の教室に数人いる規模で、あなたが作る画面の読者にも含まれている前提で考えてよい数字です。

そしてこの話は、フォントと CSS の話につながっています。同じ文章でも、**組み方しだいで読みやすさが大きく変わる**からです。

## 読む処理のどこが詰まるか

文章を読むとき、頭の中では「文字の形を見分ける」「形を音に変換する」「音から意味を取り出す」という処理が流れています。多くの人はこれをほぼ無意識にやっています。

ディスレクシアでは、このうち**形を音に変換する段階**に人一倍時間がかかるとされています。1 文字ずつは読めても、変換に力を使うぶん、意味を取る余力が削られます。

さらに、文字が詰まって並んでいると、最初の「形を見分ける」段階も難しくなります。隣の文字や上下の行が視界に割り込んで、いま読んでいる文字の形が取りにくくなるからです。

つまり読みにくさの一部は、本人の中ではなく**画面の側**にあります。だから画面を作る側が組み方を変えると、読みやすさが実際に変わります。

## 読みにくさを増幅する組み方

変換に時間がかかる読み方を想像しながら見ると、次の組み方が壁になる理由が分かります。

- **詰まった行間**: 上下の行が視界に入り込み、いま読んでいる行を見失いやすくなる
- **長すぎる行**: 行末で折り返したとき、次の行頭がどこか分からなくなる
- **両端揃え**: 行の幅に合わせて空白が不均等に引き伸ばされる。欧文では単語間の空白が縦につながって白い筋になり、日本語でも字間がガタつく
- **イタリックや全大文字**: 文字の形そのものが普段と変わり、「形を見分ける」段階の負荷が上がる

実際に、行間だけを変えた 2 つの箱を比べてみます。

<div style="background:#f8fafc;color:#1e293b;border:1px solid #cbd5e1;border-radius:8px;padding:16px;margin:16px 0;line-height:1.05;font-size:14px;">
行間が詰まっていると、上の行と下の行が視界に割り込んできて、いま読んでいる行を見失いやすくなります。この状態で長い文章を読み続けるのは誰にとっても疲れる作業ですが、文字を音に変換することに力を使っている人にとってはなおさらで、読み終えて折り返すたびに次の行頭を探し直すことになります。
</div>

<div style="background:#f8fafc;color:#1e293b;border:1px solid #cbd5e1;border-radius:8px;padding:16px;margin:16px 0;line-height:1.75;font-size:14px;">
行間が空いていると、いま読んでいる行が独立して見え、折り返したときも次の行頭を見つけやすくなります。同じくらいの長さの文章でも視界への割り込みが減るぶん追いやすくなっていて、行間が読みやすさに直接効くいちばん手軽な調整だと分かります。
</div>

## 画面側の壁を減らす CSS

画面の側が作っている壁は、本文のコンテナに数行の CSS を当てるだけで減らせます。

```css
article {
  line-height: 1.75; /* 行間を空ける。1.5 が最低ライン */
  max-width: 40em;   /* 日本語はおよそ全角 1 文字 = 1em。40 字で折り返す */
  text-align: left;  /* 両端揃えにしない */
}
```

行間・行の長さ・揃え方の 3 つで、さきほどの「視界への割り込み」「行頭を探し直す手間」「不均等な空白」に対処できます。

ただし、これで全員が読みやすくなるわけではありません。ディスレクシアの現れ方は人によってさまざまで、ちょうどよい行間や配色も人によって違います。

だからこの CSS の役割は無難な初期値を整えるところまでで、仕上げは読み手自身の調整に委ねます。

強調にはイタリックや下線ではなく**太字**を使います。日本語の斜体はそもそも読みにくく、下線はリンクと紛らわしいという別の理由もあります。

## WCAG の基準

この組み方には、Web アクセシビリティのガイドラインである WCAG（Web Content Accessibility Guidelines）に対応する基準があります。数字はさきほどの CSS とつながっています。

| 基準 | レベル | 内容 |
|---|---|---|
| 1.4.8 Visual Presentation | AAA | 1 行 80 字以内（全角なら 40 字）、両端揃えにしない、行間 1.5 以上 |
| 1.4.12 Text Spacing | AA | 読み手が行間 1.5・段落間 2em・字間 0.12em などに広げても、内容が欠けたり重なったりしない |

1.4.12 は見落としやすい観点です。読みやすい値で組むことに加えて、**読み手が自分でスタイルを上書きして間隔を広げる**ことを想定し、その余地を奪わない作りにしておく、という基準です。

たとえばテキストの入る箱に固定の高さを与えていると、読み手が行間を広げたときに文字がはみ出したり切れたりします。高さは内容に応じて伸びるようにしておきます。

## 読み手が使う道具

読み手の側では、こうした調整のための道具が実際に使われています。

- **リーディングルーラー**: いま読んでいる行だけを帯で目立たせ、上下の行を薄くするブラウザ拡張（例: [Reading Ruler](https://chromewebstore.google.com/detail/reading-ruler/phiedfcbjfjagnjikfbobmldbpmdcpfk)）。紙の上で定規やカラーバーを当てて読む方法のデジタル版
- **リーダーモード**: ブラウザ標準の機能で、ページのレイアウトを取り払い、行間・行の幅・フォントを読み手が自分で設定して読む。Microsoft Edge の[イマーシブリーダー](https://support.microsoft.com/ja-jp/topic/microsoft-edge-%E3%81%A7%E3%82%A4%E3%83%9E%E3%83%BC%E3%82%B7%E3%83%96-%E3%83%AA%E3%83%BC%E3%83%80%E3%83%BC%E3%82%92%E4%BD%BF%E7%94%A8%E3%81%99%E3%82%8B-72ac6331-2795-42eb-b3e8-c03503231f32)には、行に集中するためのラインフォーカスや音声読み上げもある
- **フォント置換**: ページ全体のフォントを、自分が読みやすいものに置き換える拡張
- **音声読み上げ**: 目で追う代わりに耳で聞く

[Helperbird](https://www.helperbird.com/) のように、これらをまとめて1つの拡張機能に収めた製品もあります。

どれも、ページの上に読み手が自分の表示を重ねる道具です。だから作る側にできるのは、読みやすい初期状態を整えること、そしてこうした道具の邪魔をしないことです。

たとえば文字を画像で置くと、フォント置換もルーラーも読み上げも効きません。本文が `main` や `p` といった本文のタグに入っていないと、リーダーモードが本文を抽出できません。

ふだんからセマンティックな HTML で書いておくことが、そのままこれらの道具への対応になります。

## 専用フォントより組み方

「ディスレクシア向けフォント」を聞いたことがあるかもしれません。文字の底を太くした OpenDyslexic などが知られています。

ただ、査読つきの研究では、読む速さも正確さも改善が確認されていません。実験では標準的なサンセリフ体のほうが好まれています。

日本語圏では、字形を判別しやすく調整した **UD フォント**（BIZ UDゴシックなど）が教科書や案内表示に広く使われています。濁点を大きくするなど読み間違いを減らす工夫があり、Windows にも標準搭載されています。

教科書向けに開発された UD デジタル教科書体については、読み書きが苦手な子どもの読む速さや正答率が改善したという教育現場の報告もあります。欧文の専用フォントとは違い、こちらは効果を支持する調査が出てきています。

ただし、フォントを替えるだけで解決するわけではありません。ガイドラインが一致して勧めているのは行間・行の長さ・揃え方という組み方の側で、フォントはそのうえでの選択肢です。

## まとめ

- ディスレクシアは知的な遅れではなく、文字を音に変換する処理の困難
- 詰まった行間・長すぎる行・両端揃えが読みにくさを増幅する
- 行間 1.5 以上・全角 40 字・左揃えを既定にし、読み手の道具（間隔の上書き・ルーラー・リーダーモード）を邪魔しない
- 専用フォントの効果は限定的で、組み方の改善が先
